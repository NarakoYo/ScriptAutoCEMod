SACE 脚本教程

SACE DSL 是 Script Auto CE 使用的受限 Minecraft 命令脚本语言。它可以把多条命令、 循环、判断、等待、参数和只读查询组合成一个可重复运行的 .sace 脚本。

适用版本：0.1.0-alpha 目标游戏：Minecraft 26.2 脚本编码：UTF-8

它能做什么

  • 按顺序运行 Minecraft 命令，例如 setblock、fill、tp、say。
  • 使用 for 循环批量生成建筑、区域、实体或连续命令。
  • 使用 if / else 根据参数、坐标、方块或计分板结果决定后续操作。
  • 使用 wait 按游戏刻暂停，让服务器有时间处理相邻操作。
  • 声明运行参数，让同一个脚本支持不同宽度、材质、目标或文本。
  • 读取执行玩家位置、方块、在线玩家、附近实体和计分板值。
  • 通过脚本库 GUI、##run 聊天指令或 /scriptautoce run 运行。
重要说明 首版只提供内置函数，不支持用户自定义函数、类、反射、Java、JavaScript、文件或网络访问。

第一个脚本

在脚本库新建一个 .sace 文件，输入以下内容：

# 输出一条消息
meta name "hello_sace"

log "Hello from SACE"
run "say Script Auto CE is ready"

保存后，可以在脚本库点击“运行”，也可以执行 ##run hello_sace。脚本名称默认来自文件或 meta name。

文件与运行方式

入口 写法 说明
脚本库 F8 浏览、创建、编辑、运行、上传和下载脚本。
聊天指令 ##run 脚本名称 [键=值...] 客户端拦截后执行；支持脚本参数和命令提示。
服务端指令 /scriptautoce run 脚本名称 供管理员、控制台或服务端场景使用。

脚本目录位于游戏根目录：

ScriptAutoCE/
  Scripts/       本地脚本，可创建子文件夹
  Shared/        服务端共享脚本
  Examples/      内置示例
  SACE脚本教程.html

文件名、文件夹名和参数值均支持 UTF-8。文件夹可以多层嵌套，脚本扩展名必须是 .sace。

脚本结构

meta 和 arg 用于声明信息，其余语句按从上到下的顺序执行。 每条语句通常写一行；分号可选。注释以 # 开始，直到行尾。 

# 1. 元数据
meta name "example"
meta on_error "stop"

# 2. 参数
arg width: int = 4 min 1 max 32

# 3. 执行语句
let material = "minecraft:stone"
for x in range(0, width) {
    run "setblock ~${x} ~ ~ ${material}"
    wait 1t
}
编写建议 先使用小范围和少量命令测试，确认坐标、材质和权限正确后，再扩大循环次数。

meta 元数据

meta 的格式是 meta 键 "静态值"。元数据值不能使用 ${...} 插值。

键 可选值 作用
name 任意文本 脚本显示名称。
on_error stop / continue 普通命令失败后停止，还是记录日志并继续。默认 stop。
on_denied stop / skip 权限不足时停止，还是跳过该命令。默认 stop。
max_commands 正整数字符串 为当前脚本设置更低的命令数量上限。
max_ticks 正整数字符串 为当前脚本设置更低的运行时长上限。 
meta name "build_wall"
meta on_error "stop"
meta on_denied "skip"
meta max_commands "500"
meta max_ticks "1200"
不能绕过的限制 危险命令策略、服务端权限、急停阈值和服务器硬上限不能被脚本元数据覆盖。

arg 参数

参数让脚本在运行时接收外部值：

arg 名称: 类型 = 默认值 [min 最小值] [max 最大值]
arg width: int = 4 min 1 max 32
arg height: int = 3 min 1 max 16
arg material: token = "minecraft:stone"
arg target: selector = "@p"
arg message: string = "hello"
arg center: vec3 = "0 64 0"
arg enabled: bool = true
arg speed: double = 1.0 min 0.1 max 10
类型 示例 可直接插入命令 说明
int 12 是 整数。
double 1.5 是 小数。
bool true / false 是 布尔值。
string "hello world" 否 任意文本，插入命令前必须使用 quote() 或 json()。
token "minecraft:stone" 是 只允许安全标识符字符：字母、数字和 _.:+/=-。
selector "@a[tag=build]" 是 Minecraft 实体选择器，例如 @a、@e、@p。
vec3 "10 64 -2" 或 "10,64,-2" 是 三个坐标值，内部统一显示为以空格分隔的坐标。

运行时可以覆盖默认值：

##run build_wall width=8 height=5 material=minecraft:stone

min 和 max 只对数值参数生效。未传入参数时使用默认值； 传入值超出范围会拒绝运行并显示诊断信息。

值与类型

值 示例 说明
整数 42、-3 用于坐标、次数、计分和数学计算。
小数 1.5、-0.25 用于速度、距离和小数坐标。
布尔值 true、false 只用于条件判断和布尔运算。
字符串 "hello" 普通文本。命令插值前必须安全编码。
安全 token minecraft:stone 由 token 参数、token() 或查询函数产生。
坐标 pos() 可直接作为 Minecraft 命令中的三坐标参数。
列表 players() 首版用于显示和日志，暂不支持索引或列表循环。

let 与 set

let 创建变量，set 修改已经存在的变量。

let width = 8
let doubled = width * 2
set width = width + 1

log "width=${width}, doubled=${doubled}"
  • 变量名必须以字母或下划线开始，可包含字母、数字和下划线。
  • 不允许重复使用 let 声明同名变量。
  • 使用未定义变量会产生脚本错误。
  • 字符串使用双引号，支持 \n、\r、\t、\" 和 \\。

表达式与运算符

表达式用于参数默认值、变量、条件和插值。运算优先级从高到低如下：

类别 运算符 示例
括号与函数 () (width + 1) * 2
单目 !、- !enabled、-speed
乘除余 *、/、% index % 2
加减 +、- x + 1
比较 <、<=、>、>= score("points", "Alex") >= 10
相等 ==、!= material != "minecraft:air"
逻辑与 && width > 0 && height > 0
逻辑或 || enabled || width > 8
类型要正确 if、&& 和 || 需要布尔值。不要直接把数字当作条件； 应写成 if count > 0。

字符串插值

在字符串中使用 ${表达式} 插入变量或函数结果：

arg name: string = "Alex"
arg radius: int = 5

let center = pos()
log "执行者=${name}, 半径=${radius}, 位置=${center}"

run "say ${name}"                         # 错误：string 不能直接进入命令
run "say ${quote(name)}"                  # 正确：安全引用
run "fill ~-${radius} ~ ~-${radius} ~${radius} ~ ~${radius} minecraft:stone"
值类型 命令中的处理
整数、小数、布尔值 直接插入。
坐标、选择器、安全 token 直接插入。
普通字符串 必须使用 quote(value) 或 json(value)。
列表 不能作为单个命令参数直接插入；可写入 log。

语句参考

run

run "Minecraft 命令"

执行一条命令，不需要写开头的斜杠。每条 run 只执行一条命令。

run "time set day"
run "weather clear"
run "setblock ~ ~1 ~ minecraft:glowstone"
run "execute as @a at @s run say hello"

命令以发起脚本的玩家权限执行，不会自动获得 OP。服务器策略会递归检查 execute ... run ... 内层命令。

log

log "输出文本"

向任务日志输出文本，不执行 Minecraft 命令。日志会显示在脚本库的运行状态中。

arg target: selector = "@p"

log "开始生成"
log "当前位置：${pos()}"
log "目标：${target}"

wait

wait 20t

暂停指定游戏刻，再继续执行。20 刻通常等于 1 秒。

run "setblock ~ ~ ~ minecraft:redstone_block"
wait 2t
run "setblock ~ ~ ~ minecraft:air"
  • 必须是字面整数，范围 1 到 72000。
  • 末尾的 t 可选。
  • 等待不会阻塞服务器线程，任务会在后续游戏刻继续。

if / else

if 条件 { ... } else { ... }
arg enabled: bool = true
let points = score("points", "@p")

if enabled && points >= 10 {
    run "say 条件满足"
} else if enabled {
    run "say 分数不足"
} else {
    log "脚本已关闭"
}

for / range

for 变量 in range(起点, 终点[, 步长]) { ... }

终点不包含在循环内。默认步长为 1，也可以使用负数倒序。

for x in range(0, 5) {
    run "setblock ~${x} ~ ~ minecraft:stone"
}

for y in range(3, 0, -1) {
    run "setblock ~ ~${y} ~ minecraft:glass"
}

循环中的 x 是整数变量。不要在循环体内用 set 修改循环变量。

fail / return

fail "错误说明"
return

fail 立即以脚本错误结束；return 立即以正常完成结束。

arg width: int = 4 min 1 max 32

if width > 16 {
    fail "宽度过大，请缩小范围"
}

run "say 开始"
return
run "say 这行不会执行"

内置函数总表

所有函数都是只读或安全编码函数。函数名区分大小写，参数数量必须完全匹配。

函数 返回 作用 能否直接插入命令
pos() vec3 执行脚本玩家的当前位置。 是
block(x, y, z) token 读取指定坐标的方块 ID。 是
players() 玩家名列表 获取当前在线玩家名。 否
entities(type, radius) UUID 列表 获取附近实体 UUID。 否
score(objective, target) int 读取计分板值。 是
token(value) token 校验并转换成安全命令 token。 是
quote(value) 编码字符串 添加双引号并转义内容。 是
json(value) JSON 字符串 把文本编码成 JSON 字符串。 是
min(a, b) 小数 取较小值。 是
max(a, b) 小数 取较大值。 是
abs(value) 数字 取绝对值。 是
round(value) int 四舍五入到整数。 是

查询函数详解

pos()

pos() -> vec3

返回脚本执行时玩家所在的位置，格式为 x y z。

let spawn = pos()
log "保存位置：${spawn}"
run "tp @p ${spawn}"
run "setblock ${spawn} minecraft:stone"

如果希望十个假人都在同一位置，应在循环前只调用一次 pos()。

block(x, y, z)

block(x, y, z) -> token

读取执行者所在世界中的方块 ID。相对坐标 ~ 以玩家位置为基准。

let below = block("~", "~-1", "~")
log "脚下方块：${below}"

if below == "minecraft:air" {
    fail "玩家脚下没有方块"
}

run "setblock ~ ~-1 ~ minecraft:stone"

不支持局部坐标 ^；绝对坐标和 ~ 相对坐标可以使用。

players() 与 entities()

players() -> 字符串列表
entities(type, radius) -> UUID 列表

players() 返回按名称排序的在线玩家名。 entities() 返回附近实体 UUID，最多 256 条，半径限制在 0 到 64。 

log "在线玩家：${players()}"
log "附近僵尸：${entities("minecraft:zombie", 16)}"
log "附近全部实体：${entities("*", 8)}"

类型可以写完整 ID，例如 minecraft:zombie，也可以写短名 zombie。使用 * 或 any 表示不过滤类型。

首版限制 这两个函数返回列表，目前适合写入日志。首版不支持列表索引、循环遍历或直接拼成一条命令参数。

score(objective, target)

score(objective, target) -> int

读取计分板目标中某个目标的分数。目标或分数不存在时返回 0。

arg player: string = "Alex"
let points = score("points", player)

if points >= 100 {
    run "say ${quote(player)} 已达到 100 分"
} else {
    log "当前分数：${points}"
}

token()、quote() 与 json()

这三个函数负责把文本安全地放入命令。

token(value) -> token
quote(value) -> 带双引号的命令参数
json(value) -> JSON 字符串
arg id: token = "minecraft:stone"
arg name: string = "Alex"

# 材质和命名空间 ID
run "setblock ~ ~ ~ ${token(id)}"

# 普通命令文本参数
run "say ${quote(name)}"

# tellraw 的 JSON 文本
run "tellraw @a {\"text\":${json(name)}}"
函数 适合场景 注意
token() 方块 ID、物品 ID、标签名、安全的单参数标识符。 包含空格、引号或特殊符号时会被拒绝。
quote() say、tell、标题文本等普通命令参数。 生成双引号包裹的文本，并转义反斜杠、双引号和换行。
json() tellraw、JSON 文本组件。 只生成 JSON 字符串值，完整 JSON 结构仍需要自己写正确。

min()、max()、abs() 与 round()

min(a, b) -> double
max(a, b) -> double
abs(value) -> int / double
round(value) -> int
let safeRadius = min(radius, 16)
let largest = max(width, height)
let distance = abs(-12)
let blocks = round(4.6)

run "fill ~-${safeRadius} ~ ~-${safeRadius} ~${safeRadius} ~ ~${safeRadius} minecraft:stone"
log "最大边=${largest}, 距离=${distance}, 方块数=${blocks}"

完整示例

示例一：在同一位置生成 10 个 Carpet 假人

需要安装 Carpet，并拥有执行 /player 命令的权限。

meta name "spawn_10_fake_players"
meta on_error "continue"
meta on_denied "stop"
meta max_commands "10"
meta max_ticks "200"

arg prefix: token = "sace_bot"

log "开始在同一位置生成 10 个假人"
let spawn = pos()

for i in range(0, 10) {
    run "player ${prefix}_${i} spawn at ${spawn}"
    wait 1t
}

log "生成完成。清理假人可使用 /player 名称 kill"

关键是 let spawn = pos() 写在循环外。这样十次命令都使用同一个坐标。 如果已经存在同名前缀的假人，请通过参数更换前缀： 

##run spawn_10_fake_players prefix=test_bot

示例二：生成一堵石墙

meta name "build_wall"
meta on_error "stop"
meta on_denied "stop"
meta max_commands "2048"

arg width: int = 8 min 1 max 64
arg height: int = 4 min 1 max 32
arg material: token = "minecraft:stone"
arg gap: int = 0 min 0 max 4

log "开始生成 ${width}x${height} 的墙"

for x in range(0, width) {
    for y in range(0, height) {
        run "setblock ~${x + gap} ~${y} ~ ${material}"
    }
    wait 1t
}

log "墙生成完成"

参数可以在聊天指令中覆盖：

##run build_wall width=12 height=5 material=minecraft:deepslate_bricks

示例三：安全发送玩家文本

meta name "safe_message"
arg message: string = "hello world"
arg target: selector = "@a"

run "say ${quote(message)}"
run "tellraw ${target} {\"text\":${json(message)}}"
log "消息已发送"
不要直接拼接字符串 run "say ${message}" 会被拒绝。使用 quote(message) 或 json(message)，防止文本被解释成额外命令参数。

权限模型

  • 所有命令使用发起玩家当前的原版权限执行。
  • 脚本不会把普通玩家提升为 OP，也不会改用控制台身份。
  • 玩家失去权限时，命令会按服务器结果被拒绝。
  • 客户端直连模式无法可靠获取结构化的权限拒绝结果，服务端安装模组时更准确。
  • 断开连接、退出游戏、任务被停止或服务器急停时，正在运行的任务会结束。

命令策略

服务器默认阻止高风险命令根。默认列表包括：

stop, op, deop, ban, ban-ip, pardon, pardon-ip, whitelist,
kick, reload, datapack, function, schedule, jfr, perf, debug,
save-off, save-on, save-all, tick, transfer

策略会检查命令根，并递归检查 execute ... run 命令。危险命令、 策略违规和调度器急停属于硬阻止，即使设置 on_denied "skip" 也不会继续。

服主配置 管理员可以通过服务端设置或 /scriptautoce config 调整阻止列表、 允许列表和各类执行上限。普通脚本不能自行解除这些限制。

执行限制

项目 默认或硬限制 说明
源码大小 64 KiB 上传和编译的最大源码大小。
编译指令数 2,000 编译器生成的内部指令数量，超过后拒绝运行。
解释器操作数 1,000,000 单次运行的解释器操作硬限制。
单次命令数 默认 10,000 服务器可调低或调整，脚本元数据只能设置更低值。
每刻命令数 默认 4 调度器逐游戏刻执行，避免一次卡死服务器。
单次运行时长 默认 6,000 刻 约 5 分钟，包含等待时间。
并发任务 每玩家 1，全局 8 管理员可调整。
单次 wait 72,000 刻 约 1 小时。

如果脚本频繁触发“阈值”“命令数”“运行时长”或“急停”错误，应缩小循环范围、 分拆为多个脚本、增加执行后的等待，或请管理员检查服务器限制。

常见错误与定位

提示或现象 常见原因 解决方式
Unknown variable 变量未用 let 创建，或名称拼写错误。 检查大小写，先声明再使用。
Expected a whole number 把小数传给了只接受整数的位置。 使用 round()，或把参数类型改为 double。
This value cannot be inserted 普通字符串直接进入 run 命令。 改用 quote(value) 或 json(value)。
Unknown function 函数名拼错，或使用了不存在的自定义函数。 只使用本文列出的内置函数，并检查大小写。
Loop step cannot be zero range() 的步长为 0。 正序使用正数，倒序使用负数。
Command root is blocked 命令被服务器安全策略阻止。 更换普通命令，或由管理员审查策略配置。
Runtime tick limit exceeded 等待时间或循环执行时间过长。 减少 wait 总量，缩小任务或拆分脚本。
Command limit exceeded 实际执行命令数达到上限。 减少循环次数，或分拆成多个脚本运行。
